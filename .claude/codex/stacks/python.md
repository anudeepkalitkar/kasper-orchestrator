### For the tester

- **Gate:** `ruff check . && mypy && pytest tests/unit` — **bare `mypy`** when `pyproject.toml` has
  a `files = [...]` key under `[tool.mypy]` (a path argument overrides it), otherwise `mypy .`.
- Tests are pytest, named `test_*.py`, mirroring the source path in `tests/unit/` and
  `tests/integration/`; fixtures in `conftest.py`, shared fakes in `tests/helpers/` — imported,
  never copy-pasted. Idioms: `pytest.raises` for the error path, `pytest.mark.parametrize` for
  boundaries, `tmp_path` and `monkeypatch` over hand-rolled setup; fake outward calls with
  `botocore.stub.Stubber`, `httpx.MockTransport`, and a passed-in clock rather than patching `time`.
- A **unit** test may not touch the network, a database, the disk outside `tmp_path`, the real
  clock, a real subprocess, or a model/weights download. Anything that needs a real collaborator —
  an Alembic migration applying and reversing, a live Redis, a Celery broker — is `tests/integration/`.
- Heavy deps (`torch`, `transformers`, `paddleocr`, `cv2`, `fitz`) may not be installed — a unit
  test importing them is in the wrong tier. Report a genuinely missing test dependency rather than
  installing it: that is a network write, not yours.

### For the reviewer

Real smells, worth a finding:

- **`Any` leaks** — a bare `Any` with no justifying comment, an unannotated signature, or a cast
  that exists only to quiet mypy.
- **Sync work in an async route** — a blocking driver, `requests`, or `time.sleep` inside
  `async def`, or an `httpx` call with no timeout.
- **A migration edited after it merged** instead of a new one, or an autogenerated one committed
  unread (type changes, server defaults, index renames are the misses).
- **Heavy imports at module top level** in OCR/ML code — they belong inside the function that uses
  them, marked `# lazy: heavy dep`.
- **A boto3 client built per call or per request** rather than once per process; a hardcoded region,
  account id, or key; a credential or presigned URL in a log line.
- SQL built by f-string or `%`; a bare `except:` or `except Exception: pass`; a mutable default
  argument; an ORM row returned straight from a route while it carries a password hash or token;
  N+1 queries, an unindexed foreign key, `timestamp` where `timestamptz` is meant.

False positives — skip unless you have evidence in this codebase:

- "Add error handling" where a FastAPI exception handler, a context manager, or the caller already
  owns the error path. Trace one caller before flagging.
- "Missing validation" on an internal helper whose callers validate; "magic number" for status
  codes, `0`/`-1`, or an obvious single-use local.
- "Function too long" for an exhaustive `match`/dispatch table — length is not complexity;
  "missing docstring" on a private helper whose name says it; "N+1" on a fixed, small-cardinality
  loop; a lazy import marked `# lazy:`; an `Any` that already carries its justifying comment.
